## 阻断验收的问题

### P1：因子 C 关闭时仍执行其止损，消融对照不独立

run_execution_simulation 在实际再入场成交后无条件设置 stop_timer，并无条件执行 5% 止损。use_factor_c 仅控制再入场选择，没有控制止损。

- 合成反例在 use_factor_c=False 时产生 STOP_LOSS_5PCT 成交。
- 真实 NOW C0 在 2014 年起的研究区间发生 15 次止损；C7 为 11 次。
- 因此 C0、C1、C2、C4 都可能包含本应关闭的 C 规则，当前差异不能被解释为声明的因子效果。

### P1：基准首日两次下单，初始买单被取消

实验先在循环前提交 Benchmark Initial Buy，首日入金后再次提交 Monthly benchmark investment。SharedExecutor 先取消旧单，再按当日 ID 检测已存在的历史订单，导致第二次调用也不留下有效单。

- 八交易日合成反例：基准成交 0 笔、现金 11000、初始订单 CANCELLED、无待成交单。
- NOW 研究从 2014-04-16 开始，基准首次实际成交到 2014-05-02 才发生。
- 附件自己的旧复核结果中，1313423.13 与独立反证 1320772.48 相差 7349.35，不能称为“对齐”。期末现金零和成交笔数相同不足以证明成交路径一致。

### P1：测试通过不能支持声明的覆盖程度

- test_05 仅断言 round_trips >= 1，没有核验再入场、止损或 DCA 不重置计时器。
- 在内存中禁用止损并禁用泡沫顶两条再入场分支，六项测试仍全部通过。
- test_01 的冲突场景在测试里重写循环，未调用待审执行函数处理该冲突。
- test_02 测底层执行器的末日单，没有缺价延迟用例。
- test_04 仅检查第 12 日有信号、第 13 日无信号，未分别证明刷新、过期和 MA10 无例外。
- test_06 检查底层记账恒等式，未断言交易日间隔输出。

### P1：旧复核脚本未适配 v2 参数，其 C7 实际没有开启 C 的入场规则

verify_factorial_claims.py 调用 run_execution_simulation(signals) 时未传入新增的 use_factor_c/use_factor_a 参数。它的 C7 标签不能当作 C7 的独立交叉验收。

- 在该脚本使用的 2012 年起全样本，省略参数终值 589160.80。
- 使用相同数据并显式传入两个 True，终值为 517268.63。
- 此处与 2014 年起主矩阵是不同区间，不能相互混比。

### P1：仍硬编码预热起点，未建立承诺的生产双轨对照

准备函数没有计算生产 Gap/signal_ready 依赖，主入口直接把 NOW、QQQ、SPY 都裁到 2014-04-16。之后生成信号时再次计算 20/90 日滚动窗口、拐点 shift、迟滞和锁存，从而丢失截点之前的部分状态。历史分段也重新开始。

统一研究日期可作为约定，但不能声称动态还原生产门禁。原始生产运行及其结果没有作为主入口产物输出，附件中生产对照数值缺少在此脚本内的复现路径。

### P2：锁存仍在最终迟滞过滤之前消耗

锁存循环设置 raw_panic_arr 后立即关闭 latch，随后才调用 apply_hys。合成反例原始候选为第 1、5 日，最终信号只有第 1 日；第 5 日虽被抑制，锁存已经消耗。旧问题未根除。

### P2：部分交付与文本数字不一致

- 当前主入口计算 NOW results 后没有保存，实际只输出 QQQ/SPY 两份 CSV。现有 NOW CSV 数字可部分复算，但一键重跑不会重新生成该文件。
- df_in_sample 仍定义后未使用；QQQ/SPY 没有历史分段表。
- evaluate_signals 注释声称趋势/再入场前向收益评价，实际返回没有相关指标。
- 没有导出逐笔配对、年度归因、卖出到买回空仓间隔及相应机会成本底稿。
- CSV 的 QQQ C0 XIRR 为 16.27%，附件为 15.65%；SPY C0 为 14.50%，附件为 13.16%。其他行也有类似差异。
- QQQ/SPY C1 与 C0 相同，不能说 C0 严格优于所有候选。
- 无逐笔归因证据，不能把 B 造成的终值变化直接归因于“震荡买入带来摩擦”。
