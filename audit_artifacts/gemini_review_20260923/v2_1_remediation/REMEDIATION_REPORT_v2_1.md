## 六、 客观量化发现与模型表现解释 (Strictly Fact-Based)

在消除了所有控制组污染、首日取消 Bug 和锁存提前消耗问题后，实验数据呈现出高度一致的真实量化规律：

1. **因子 C (再入场状态机 + 5% 止损) 在高成长科技股中存在严重的负 Alpha**：
   - 当 C 因子被严格隔离后，在 NOW 上，任何包含因子 C 的组合（C3, C5, C6, C7）终值全部断崖式下跌（终值仅在 17 万 ~ 28 万之间），相比基准 (\$75.1 万) 和 C0 (\$44.5 万) 发生了大幅跑输。
   - 逐笔底稿揭示了真实机理：NOW 处于长期高波动成长牛市中，5% 止损门槛过于狭窄，导致在每次再入场后遭遇正常市场震荡时频繁触发止损（触发 20~21 次止损），在底部割肉后踏空主升浪，且短期往返率激增至 48.98%。
2. **因子 B (恐慌锁存) 展现出显著正向贡献**：
   - 单独引入因子 B (C2_Panic_Latch) 时，NOW 终值从 C0 的 \$44.5 万提升至 \$55.8 万，XIRR 从 14.47% 提升至 17.51%（提升 3.04 个百分点），谷底漏报率从 81.25% 显著下降至 64.58%。
   - 在 QQQ 上，C2 终值同样从 \$39.6 万提升至 \$48.0 万，表现突出。
3. **因子 A (分数解耦) 影响中性微偏保守**：
   - 因子 A 将多空极值解耦后，信号更加严格，在各资产上收益和回撤与 C0 基本持平或略微保守。
4. **决策依据与工程边界**：
   - **严禁将 C7 合并入生产环境的禁令必须继续坚决执行**。此前试图将 C7 全量合入的方案已被证明在量化逻辑上存在严重缺陷。
   - 生产环境原样保持现状。
