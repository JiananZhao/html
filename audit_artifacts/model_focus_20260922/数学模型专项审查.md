# 数学模型专项审查（2026-09-22）

## 范围与结论

检查当前 IGV、SMH、NOW、QQQ/SPY 的核心特征与决策公式，重点为数学含义和信号可靠性，不以收益率核算为重点。只新增审查脚本和报告，未修改生产模型。不能据此宣称其他模型全部通过验收。

复现：在仓库根目录运行 `python audit_artifacts/model_focus_20260922/check_math.py`。结果见同目录 `math_observations.json`。脚本禁止网络连接，直接抽取部分生产源码 AST 执行，并对本地主数据做公式诊断；未运行完整交易执行器，也未完成样本外预测能力检验。

## 优先修正

### 1. 广度分母包含不可观测成分股

位置：micro_bubble_radar.py:135、smh_bubble_radar.py:132。

浮点 NaN 与均线比较得到 False，之后对布尔结果调用 notna() 无法识别原来的缺价/预热不足，分母仍包含这些股票。应先计算价格与均线均可用的 valid 掩码，分母只统计有效成员；无有效成员应输出不可用状态。

依照现有加载政策复算，IGV 自 2012 年起有 2,129 个日期变化，最大差异 46.67 个百分点；SMH 自 2009 年起有 412 个日期变化，最大差异 13.33 个百分点。这只是修复缺失分母，并不解决使用当前成分股回溯历史造成的成分股选择偏差。还应提供历史成分成员与覆盖率，缺少时明确是固定篮子代理。

### 2. 带符号的 Gap 分位阈值不能直接作为评分分母

位置：reflexivity_interactive_chart.py:61。

当前 gap_score=clip(Gap/Gap_Upper*15,0,30)。当 Gap_Upper<0，分数对 Gap 的方向反转；当其接近零则不稳定。例：Gap=-2、Gap_Upper=-1，得到满项分30，尽管 Gap 低于上阈值。

本地数据自2009年起，QQQ、SPY 的非正上阈值分别出现110、146个日期，并非只有理论可能。建议使用历史经验分位数的单调映射，或相对中位数、以正尺度归一的偏离度；不要仅加 epsilon 掩盖符号问题。

### 3. 并列值和退化分布缺少合理评分政策

位置：now_reflexivity_radar.py:184。

expanding_rank 使用 bisect_right 的插入前位置除以插入后长度。200个全零观测末端得到99.5，而非“无变化、无区分信息”。这是一种上侧并列排序约定的结果，不能自动解释成异常强烈，尤其影响大量零值或阶梯更新的基本面变量。

应明确采用并列中秩或其他统一约定，对常数历史、低覆盖率、未预热分别设定政策。未经预热的 NaN 不应经 fillna(50) 自动获得有效交易资格。分位数不能保证非平稳序列或常数序列呈均匀分布，也不会令各因子独立。

### 4. 深跌过滤器覆盖系统性退出

位置：now_reflexivity_radar.py:273。

raw_sell=(cond_bubble|cond_bear)&~recently_crashed；过去20交易日曾偏离MA200低于-20%，便同时禁止泡沫退出与宏观危机退出。按当前数据，132个 cond_bear 成立的日期中86个被该规则屏蔽，首个例子为2022-04-22。这是信号条件日期数，不是86笔交易或86次实际持仓止损。

这不是代数计算错误，但风险目标存在冲突：超跌不保证后续反弹。应立即确定风险退出与避免追跌的优先级，分别测试“深跌后继续下跌”及“深跌后迅速反弹”；不能为改善一个历史个案直接删除过滤器或修改阈值。

## 必须明确模型含义并安排验证

### 5. LPPLS 高拟合度不能充当泡沫识别证据

位置：micro_bubble_radar.py:76、smh_bubble_radar.py:73。

对 P_t=100 exp(0.001t)、131个观测的普通恒定对数增长序列，直接执行现有27组参数搜索得到 LPPLS_R2=0.9992376167；更简单的对数直线 R2=1。说明高R2没有识别出“超指数增长”的增量证据。该反例不等于整个综合模型一定误报，因为总分还有其他分项。

先将其定位为候选曲线拟合特征，增加普通指数增长和无泡沫基线对照，以及多窗口稳定性、样本外增量价值检查。若宣称实现正式LPPLS识别，需要独立说明参数搜索、过滤条件和不确定性。

理论参考：[Filimonov 与 Sornette 的 LPPLS 校准论文](https://arxiv.org/abs/1108.0099)。本项目的局部参数网格与R2指标不能仅凭名称视作完整实现。

### 6. 相空间能量变化率混合上涨与下跌方向

位置：core_engine/phase_space.py:20、now_reflexivity_radar.py:204。

D=v(q+100a)。当a=0，q=20、v=1与q=-20、v=-1都产生D=20。一种是均线上方扩张，一种是均线下方加速偏离。直接将高D分位数加入“过热分”缺乏单一方向解释。

建议区分上行过热与下行失稳，按象限及任务定义解释，不把D直接当作顶部或底部概率。在连续且v=dq/dt、a=dv/dt的理想设定中，该式对应候选量 E=(q²+100v²)/2 的导数；当前不同窗口的有限差分不是该连续导数的精确实现。若以交易日为时间单位，系数100需要时间平方单位或相应的无量纲化解释。

没有指定并验证状态运动方程及Lyapunov条件，不能据此证明市场稳定或必然均值回归。参考：[MIT Lyapunov Analysis](https://underactuated.mit.edu/lyapunov.html)。无需为贴合物理类比立即引入Duffing方程。

### 7. 动态Beta残差缺少截距

位置：reflexivity_interactive_chart.py:46、now_reflexivity_radar.py:160，以及其他复用模型。

beta=Cov(Y,X)/Var(X)后直接预测beta X；若要解释为带截距OLS的拟合残差，应同时使用 alpha=mean(Y)-beta mean(X)。逐日按200日窗口标准化，不能保证后续252日回归窗口内X、Y均值为零。截断beta亦需说明其约束含义。

本地QQQ、SPY省略截距的绝对值中位数分别约0.565、0.581（Z分数量纲），并非纯舍入误差。可保留现式作为明确声明的启发式指标，或验证加入截距/其他信用因子后的样本外价值；不要直接称它为信用因素决定的合理价格。

### 8. 技术偏离与资产内在价值应区分

扩展log趋势残差和MA200偏离度衡量相对历史路径的位置，不包含完整现金流与贴现结构。去掉未来函数后它们具有更好的时序因果性，但仍不能据此声称获得公允价值。若要承担估值任务，应另外加入来源可核验、按公告可用时间对齐的基本面与利率信息。

## 建议执行顺序

1. 先修广度分母、带符号阈值除法、并列值与可用状态，锁定反例断言；单列新旧信号差异。
2. 明确风险退出优先级、过热与下行风险含义、Gap是否OLS残差；策略改动另设版本。
3. 固定数据、切分与事件定义，比较M0（位置+宏观）、M1（添加一阶速度v）、M2（再添加加速度a或D）。检查预警命中、误报、提前量、跨资产稳定性与空仓时长，再评估最终财富。不凭一次样本内收益判断成败。

本次没有完成上述样本外实验，因此尚不能证明任何复杂新增特征提升了预测能力。NOW前三个价格派生分项共占65%权重，但实测两两Spearman相关性约-0.005至0.313，不应把“同源”直接说成“已证实高度共线”。增量信息应通过消融实验检验。
